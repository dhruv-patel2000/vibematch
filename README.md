Welcome to the VibeMatch mobile application! This is a complete Flutter project for a random live video chat matchmaking platform.

## Features
- Real-time Video Chat using WebRTC
- Matchmaking System
- VIP Memberships & Virtual Coins
- Clean & Modern UI

## Getting Started
To run this project:
1. Ensure you have the Flutter SDK installed.
2. Run lutter pub get to install dependencies.
3. Configure the backend URL in lib/core/config/app_config.dart.
4. Run the app on your emulator or real device.
